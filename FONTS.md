# Fonts

Every typeface this site loads, embeds or outlines is open-licensed (SIL Open Font License 1.1) and free for commercial use.

## Web fonts

This site loads no web fonts. Its CSS uses system font stacks only.

## Logo artwork

`assets/logo.svg` are drawn from **Nunito Bold** (SIL OFL 1.1, https://github.com/googlefonts/nunito). The letters were converted to outlines, so no font file is shipped.

## System fonts

The CSS lists system fonts (for example Segoe UI, Georgia or Impact) only as fallbacks. They are drawn by the visitor's own device;
this site does not ship or embed them.
